## Sessions

```python
from data_models.session import SessionLocal, engine, get_db

db = SessionLocal()
try:
    ...
    db.commit()
finally:
    db.close()
```

As a FastAPI dependency:

```python
from fastapi import Depends
from sqlalchemy.orm import Session
from data_models.session import get_db

@app.post("/auth/login/")
def login(req: LoginRequest, db: Session = Depends(get_db)):
    user = db.query(User).filter(User.email == req.email).first()
    if user is None:
        raise HTTPException(404, "Invalid credentials")   # reaches the client as 404
    ...
```

The connection URL is built from `settings.Settings`:
`postgresql://<DB_USER>:<DB_PASSWORD>@<DB_HOST>:<DB_PORT>/<DB_NAME>`.

## Models

### `User`

```python
from data_models.users import User

user = User(email="a@b.c", username="alice", password_hash=hash_password(pw))
db.add(user); db.commit(); db.refresh(user)
print(user.id)     # UUID, generated by PostgreSQL
```

| Column | Type | Notes |
|---|---|---|
| `id` | UUID | PK, `uuid_generate_v4()` |
| `email` | String | unique, indexed |
| `username` | VARCHAR(255) | unique, indexed |
| `password_hash` | String | Argon2 |
| `created_at` | DateTime(tz) | `now()` |

### `Document` / `Chunk` / `Embedding`

```python
from data_models.chunks import Document, Chunk, Embedding

doc = Document(user_id=user.id, filename="report.pdf",
               original_path="/docs/report.pdf", modality="text")
db.add(doc); db.commit(); db.refresh(doc)

db.add(Chunk(id=chunk_hash, user_id=user.id, document_id=doc.id,
             chunk_index=0, start_char=0, end_char=250, text="..."))
db.add(Embedding(chunk_id=chunk_hash, user_id=user.id, faiss_id=0))
db.commit()
```

`Chunk.id` is the content-addressed hash from the chunker, not a surrogate key —
re-ingesting the same bytes collides on the PK, which is the intended idempotency.

### `CacheTopic`

PK `(user_id, topic)`, plus `level`, `score`, `last_accessed`. Note there is no
column for chunk IDs.

### `HistorySession` / `HistoryTurn`

```python
from data_models.history import HistorySession, HistoryTurn

session = HistorySession(user_id=user.id)
db.add(session); db.flush()

db.add(HistoryTurn(session_id=session.id, user_id=user.id,
                   turn_index=1, query_text="user: what causes it?"))
db.commit()
```

`query_text` embeds the role as a `"user: "` / `"assistant: "` prefix, parsed
back on read.

## Creating the schema

```python
from db.base import Base
from data_models.session import engine
import data_models.users, data_models.chunks, data_models.cache, data_models.history

Base.metadata.create_all(bind=engine)
```

Import every model module first — `create_all` only creates what has been
registered on `Base`. The `uuid-ossp` extension must already exist.

## Query patterns

Always filter by `user_id`. It is the isolation boundary:

```python
rows = (db.query(Chunk)
          .filter(Chunk.id.in_(chunk_ids), Chunk.user_id == user_id)
          .all())

rows = (db.query(Chunk.id, Document.original_path)
          .join(Document, Chunk.document_id == Document.id)
          .filter(Chunk.id.in_(chunk_ids), Chunk.user_id == user_id)
          .all())
```

Deleting a user cascades to documents, chunks, embeddings, cache and history:

```python
db.query(User).filter(User.id == user_id).delete()
db.commit()
```
